# 🍲 Rajasthan Rasoi — Authentic Food Ordering Website

A responsive and interactive Rajasthani food ordering web application built with **HTML5, Modern CSS3, and Vanilla JavaScript**.

Rajasthan Rasoi is designed to bring the rich flavors and royal food culture of Rajasthan to a digital food-ordering experience.

## 🚀 Features

### 🍽️ 47-Item Royal Menu

The menu contains **47 authentic vegetarian Rajasthani food items**, organized into four categories:

* **Main Course — 15 Items**

  * Dal Baati Churma
  * Ker Sangri
  * Gatte Ki Sabzi
  * Panchmel Dal
  * Papad Ki Sabzi
  * Kadhi
  * And more

* **Snacks & Namkeen — 8 Items**

  * Pyaz Kachori
  * Mirchi Bada
  * Bikaneri Bhujia
  * And more

* **Sweets & Mithai — 18 Items**

  * Ghevar
  * Mawa Kachori
  * Malpua
  * Moong Dal Halwa
  * And more

* **Rajasthani Drinks — 6 Items**

  * Chaas
  * Thandai
  * Makhaniya Lassi
  * And more

## 🛒 Dynamic Cart System

* Add items to the cart using the **Add to Thali** button.
* Buttons dynamically change into **+ / − quantity controls**.
* Real-time cart quantity updates.
* Floating cart badge displays the current number of items.
* Individual item quantity modification.

## 🧺 Slide-Out Cart Drawer

The interactive cart drawer provides:

* Item-wise cart breakdown
* Quantity controls
* Live subtotal calculation
* GST calculation
* Delivery charges
* Final order total

## 💳 Checkout & Payment

The checkout system includes:

* Customer details validation
* Name, contact number, and address fields
* Multiple payment options:

  * UPI
  * Cards
  * Net Banking
  * Wallets
  * Cash on Delivery (COD)
* Dynamic UPI QR code
* Automatic Order ID generation
* Order confirmation screen
* Digital order receipt

## 🎯 Project Objective

The objective of **Rajasthan Rasoi** is to showcase authentic Rajasthani vegetarian cuisine through an attractive, interactive, and user-friendly online food-ordering experience.

The project combines traditional Rajasthani visual elements with modern web technologies to create a **royal digital food experience**.
